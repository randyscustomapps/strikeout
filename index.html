Help

How to use it

Other combines — everyone besides you on this land: out with you now, or the ones who didn’t follow.

Following me. Following on is their side (usually Right). Skip jumps over the pack: followers out, then the whole crew back. Outside leaves room for the followers only, so the crop stays outside.

Not following — you go out alone. Count the others on the rows below. Didn’t follow, Following on, and Skip / Outside stay in place but grayed out. They are not used until Following me is on again, and Didn’t follow counts are not added again.

Didn’t follow — while Following me, for the ones who peeled off. Tap the row to open it, then set each header size (a 35' and a 40' can both be on). Each size’s cut is added once, like Outside, not as a full Skip pack jump. Tap the row again to close it. Under Not following that row is still there, just not tappable.

Settings — slides in from the right. Drag it back the same way. Halfway across, or a quick flick, finishes it. Let go earlier and it springs back. Same as the back arrow. A vertical drag still scrolls.

Help and Privacy — slide in over Settings and drag back the same way, straight to Settings.

Overlap — one row on the field showing each head and the total. Tap it to open the − and + buttons, tap again to fold it away.

Turn — the way you turn off the pass you're driving. North, then east to come back south, is Right.

Count from the line you're on now, including the first pass. On 78 and it says +5? Go to 83, or 73 if the numbers count down. Enter Current row, then Count up or Count down. Go to is that line plus or minus the move.

Auto lives in Settings and starts on for a new install. Turn it on or off there. Auto reads which way the passes run, North–South or East–West, from the GPS heading, so there is nothing to set. Until a heading arrives it keeps the last direction. The field shows a one-line status only while Auto is on. After a real turnaround, Current row advances once you’ve gone the confirm distance the new way. A short reverse does not. If location is denied, Auto turns off and the typed row still works. On iPhone, choose Allow While Using App (not Allow Once) the first time.

Quick check when every header matches yours. Following + Skip: 2 × others + 1 (two others → +5, four others → +9). Outside or Not following: others + 1 (three others → +4, four others → +5). Mixed sizes: use the card. A leftover strip is not always fixed by more lines.

Nudge is left or right after the turn, on the new heading, so it matches the GPS arrows. Farther out is away from cut land; back in is toward it. Add it to any nudge already set.

Headers

My header is your GPS line width.

Add every header size your crew runs. Same size twice? You only need it once. In field mode you just set how many are following.

How it works it out

Your GPS lines are spaced at your header width. Everyone's cut counts as header width minus overlap.

The field card shows whichever way needs the smaller nudge. The other way is the last line of the breakdown above. The same result sits under the headers in Settings and updates as you type.

Auto distance

Current row moves only after the phone has traveled this far the new way. A short backup, such as for plugged crop, does not count. Default is 100 ft.

iPhone forgets a tap on Allow each time Strikeout restarts. To stop it asking, open this site in Safari, tap aA → Website Settings → Location → Allow.

On this phone

Your settings stay on this phone — headers, counts, current row, count direction, last pass direction, auto, Didn’t follow, Following on, Skip/Outside, theme, and the rest. They survive offline use and Update now. Only Reset everything clears them.

Location is for Auto row advance, and for Screen set to Auto so day and night follow sunrise and sunset. It does not use the light sensor. Your setup stays on this phone.

Keep screen on stops the phone going to sleep in field mode. Extra-dim night is darker still, for pitch-black nights.
